## 产品一句话速览

- **三个界面**：桌面组件（进度条 + 今日待办 + 最近想法，每区最多 3 条；只读 + 可直接打勾/推迟）／工作区（计划、收集箱、AI 洞察、设置；列表点名字进详情；带关键词+标签搜索）／随手记（全局快捷键 + 工具内，失焦不丢草稿）。
- **一条 AI 暗线**：定时回顾想法 + 工作，生成洞察卡片（串联/挖关联/指方向），可点进去对话深挖、结论回写想法；AI 任何改数据都先确认；扫描范围由 AI 主动问；接口厂商无关（谁的 key 都能用）。
- **生命周期**：删除走回收站可恢复、删计划可保留 todo、想法可归档、转计划可撤销（有边界）、todo 可跨计划移动、进度按现存任务算。
- **技术**：Tauri 单应用 + 本地 SQLite + key 进钥匙串；桌面 v1 做悬浮面板；纯 mac、单人、纯本地（有手动导出兜底，不做恢复）。
