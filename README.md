## 产品一句话速览

- **三个界面**：桌面组件（进度条 + 今日待办 + 最近想法，每区最多 3 条；只读 + 可直接打勾/推迟）／工作区（计划、收集箱、AI 洞察、设置；列表点名字进详情；带关键词+标签搜索）／随手记（全局快捷键 + 工具内，失焦不丢草稿）。
- **一条 AI 暗线**：定时回顾想法 + 工作，生成洞察卡片（串联/挖关联/指方向），可点进去对话深挖、结论回写想法；小动作 AI 直接做且可撤销，大动作要确认；扫描范围由 AI 主动问。
- **生命周期定清了**：删除走回收站可恢复、删计划可保留 todo、想法可归档、转计划可撤销、todo 可跨计划移动、进度按现存任务算。
- **范围**：仅 mac、单人、工作 + 学习思考；不做手机端 / 多设备同步 / 协作（但有手动数据导出兜底）。

详细场景、信息结构、动线、生命周期规则、边界、验收标准，见上面的 spec。
