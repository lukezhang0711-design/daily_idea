## 1. 要做什么 / 解决什么问题

我想要一个**看得见的个人计划工具**，核心是四件事：
- 能写 todo、能管理我的计划
- 能调整这些计划/todo 的状态
- 能随时瞄一眼看到自己计划的进度
- 能随手记录脑子里冒出来的想法

它不只是个记录本，更想做成一个**会动脑子的思考伙伴**：我零碎地记想法，AI 定时回顾这些想法和我最近做的事，帮我找关联、给启发。

---

## 2. 已经定下来的决策 ✅

| 决策点 | 定了什么 | 为什么这么选 |
|---|---|---|
| **工具形态** | 贴在 macOS 桌面背景上，像小组件/壁纸一样常驻可见 | 想瞄一眼就看到进度，不用专门打开某个 App |
| **看 vs. 改** | 桌面背景上**只展示进度（只读）**；想动手时**点一下弹出编辑窗口**来写/改 | 壁纸式的东西天然只能看，编辑放到弹窗里，兼顾"一眼可见"和"好编辑" |
| **计划结构** | **两层**：大计划（项目/目标）下面挂 todo；也允许不属于任何计划的零散 todo。进度 = 这个计划下完成了多少条 todo | 既能管大目标，也能记零碎小事 |
| **想法定位** | 一个**独立的想法收集箱**，随手丢；觉得靠谱了能**一键变成计划或 todo**（是计划的"原料入口"） | 记想法的当下不想被分类打断，事后再消化 |
| **AI 回顾** | AI 定时回顾"想法 + 最近做的事"→ 找关联、给启发。形式上**两者都要**：①定时自动生成的洞察卡片 ②随时能主动问的助手 | 既要被动收到提醒，也要能在想起来时当场问 |

## 3. 完整功能清单（目前的理解）

1. **计划 / todo 管理** —— 两层结构，每条有状态（未做 / 进行中 / 完成）
2. **进度可视化** —— 桌面背景上常驻展示，瞄一眼就懂
3. **点击弹出编辑** —— 桌面只读，点一下打开编辑窗写/改
4. **想法收集箱** —— 随手记，能一键转成计划/todo
5. **AI 定时洞察卡片** —— 比如每天/每周自动生成一段回顾
6. **AI 随时问答** —— 想起来就问"看看我最近这些想法有啥可做的"
