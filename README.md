## 1. 要做什么 / 解决什么问题

我是个 PM，想要一个**看得见的"第二大脑"**，核心是四件事：
- 能写 todo、能管理我的计划
- 能调整这些计划/todo 的状态
- 能随时瞄一眼看到自己计划的进度
- 能随手记录脑子里冒出来的想法

它不只是个记录本，更是个**会动脑子的思考伙伴**：我零碎地记想法，AI 定时回顾这些想法和我最近做的事，帮我串联、挖出我自己都没注意到的潜在关联、给我指方向 —— 借 AI 的"举一反三"把点子盘活。

**装的内容**：主要是 ①工作/产品 PM 相关（需求、项目、功能规划、复盘）+ ②学习/思考/灵感（产品判断、反思、点子）。不含纯生活目标（健身读书那类）。

## 2. 已经定下来的决策 ✅

| 决策点 | 定了什么 | 为什么这么选 |
|---|---|---|
| **工具形态** | 贴在 mac 桌面背景上，像小组件/壁纸一样常驻可见 | 想瞄一眼就看到进度，不用专门打开某个 App |
| **看 vs. 改** | 桌面背景上**只展示进度（只读）**；想动手时**点一下弹出编辑窗口**来写/改 | 壁纸式天然只能看，编辑放弹窗，兼顾"一眼可见"和"好编辑" |
| **桌面展示风格** | **进度条列表**：每个计划一行 + 一根进度条 + 完成数（如 6/8） | 信息量和清爽度平衡最好，能放多个计划 |
| **计划结构** | **两层**：大计划（项目/目标）下挂 todo；也允许零散 todo。进度 = 计划下完成多少条 | 既能管大目标，也能记零碎小事 |
| **想法定位** | 一个**独立想法收集箱**，随手丢；觉得靠谱了能**一键变成计划或 todo** | 记的当下不想被分类打断，事后再消化 |
| **想法捕捉方式** | ①**全局快捷键**：电脑任何地方一按弹小输入框，打完就走；②工具内顺手记。纯文字、零摩擦。**手机端先不做（仅 mac）** | 灵感来去快，记录要无摩擦；先把 mac 做扎实 |
| **AI 的职责** | 思考伙伴：**串联**想法与工作、**挖掘潜在关联**、**指明方向**（生成式联想，不是机械的催办提醒） | 这是工具最值钱的地方，要"惊艳"不要"鸡肋" |
| **AI 交互形态** | **两种都要**：洞察卡片速览 + 哪张想深挖就点进去转成对话接着聊 | 既能快速扫，也能顺一个点深挖 |
| **AI 节奏与提醒** | 多久生成一次、要不要弹通知，**都做成设置让我自己调**（给合理默认值） | 不同时期需求不同，灵活最好 |

## 3. 完整功能清单（目前的理解）

1. **计划 / todo 管理** —— 两层结构，每条有状态（未做 / 进行中 / 完成）
2. **进度可视化** —— 桌面背景常驻展示（进度条列表风格），瞄一眼就懂
3. **点击弹出编辑** —— 桌面只读，点一下打开编辑窗写/改
4. **想法收集箱** —— 全局快捷键 / 工具内随手记，能一键转成计划/todo
5. **AI 洞察卡片** —— 定时生成（频率自定），串联想法与工作、挖关联、指方向
6. **AI 对话深挖** —— 卡片点进去能转成一问一答，顺着深聊
7. **设置** —— AI 频率、提醒开关等
