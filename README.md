## 产品一句话速览

- **三个界面**：桌面只读组件（进度条 + 今日待办 + 最近想法）／工作区（计划、收集箱、AI 洞察、设置，列表点名字进详情）／随手记（全局快捷键 + 工具内）。
- **一条 AI 暗线**：定时回顾想法 + 工作，生成洞察卡片（串联 / 挖关联 / 指方向），可点进去对话深挖；想法可在 AI 协助下转成计划。
- **范围**：仅 mac、单人、工作 + 学习思考；不做手机端 / 多设备同步 / 协作。

详细场景、信息结构、动线、边界、验收标准，见上面的 spec。
