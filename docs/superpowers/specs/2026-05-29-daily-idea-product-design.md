# 小想法 · 产品设计文档（Product Spec）

> **一句话定位**：一个 PM 的"第二大脑" —— 左手是手头的产品工作（计划 / todo / 进度），右手是平时积累的想法和判断，AI 帮你把两边串起来、挖出潜在关联、指点方向。常驻在 mac 桌面背景上瞄一眼就懂，点一下能编辑，随手能记想法。

**版本**：v3（两轮评审 + codex 对抗式审查后定稿）
**日期**：2026-05-29
**状态**：核心产品决策已定，待最终评审
**范围说明**：本文档只写**产品方案**（要做什么、给谁、怎么用、长什么样）。**技术如何实现不在此文档**（怎么贴到桌面、数据存哪、AI 怎么接，是下一阶段单独定的事，见第 14 节）。

---

## 1. 背景与要解决的问题

我是一名产品经理，日常有三个一直没被很好解决的痛点：

1. **想法易丢** —— 灵感来得快去得也快，没有一个零摩擦的地方随手接住，回头就忘了。
2. **进度不可见** —— 计划散落在各处，没有一个一眼就能看到"整体进展到哪了"的地方。
3. **想法和工作脱节** —— 记下的零碎想法和正在做的事各自躺着，没人帮我把它们联系起来、提醒我"这个点子其实能用上"。

这个工具就是来同时解决这三件事的：**接得住想法、看得见进度、还能帮我把两边串起来思考。**

---

## 2. 目标用户与内容范围

- **目标用户**：我自己（单人使用，PM）。v1 不考虑多人/协作。
- **装什么内容**：① 工作 / 产品 PM 相关（需求、项目、功能规划、上线节点、复盘）；② 学习 / 思考 / 灵感（产品判断、阶段反思、点子）。
- **内容可打标签**（AI 推荐、我也能自己改），"工作 / 学习"这种大类也用标签表达，方便日后搜索和组织。

---

## 3. 核心理念（三条）

1. **看得见** —— 进度常驻桌面背景，瞄一眼就懂，不用专门打开什么。
2. **零摩擦记录** —— 想法冒出来的那一秒就能接住，纯文字、不用分类、打完就走。
3. **AI 串联思考** —— 不只是记录本，AI 借"举一反三"的能力把零散想法和手头工作连起来，给我启发和方向。

---

## 4. 核心使用场景

### 场景一：灵感闪现 → 随手记
按全局快捷键（默认 ⌘⇧Space），任何应用里弹出极简输入框，打一句回车，进收集箱。不打断手头的事。打字途中即使被打断（锁屏/切走）也**不丢草稿**，只有主动 Esc 才算放弃。

### 场景二：坐下来理计划
打开工作区，建计划、加 todo、设截止日期和优先级、调状态。能管"大计划 + 下面的 todo"，也能记不属于任何计划的零散待办。

### 场景三：瞄一眼桌面
扫一眼右上角组件：① 各计划进度 ② 今天/快到期待办 ③ 最近想法。看到今日待办可**直接打勾完成或推迟**；想看细节点名字直达详情。

### 场景四：AI 回顾，给我洞察
按设定频率自动生成，或随时主动唤起。AI 回顾想法 + 工作，生成洞察卡片（串联 / 挖关联 / 指方向）。**手动唤起时 AI 会先问"这次扫全部还是只看最近"**；定时自动那次默认扫得宽（全部历史想法 + 进行中的计划）。哪张想深挖点进去转成对话。

### 场景五：想法变计划 / 待办
想法详情可"转成计划"（AI 起草：归到哪个计划或新建、拆成几条 todo，我改一改确认）或"转成一条 todo"（挂到某计划或留作零散）。**转完有"撤销"可一键反悔**（边界见第 10 节）。

## 5. 信息结构（概念对象）

概念层描述，具体字段技术阶段再细化。

| 对象 | 包含什么 | 状态 |
|---|---|---|
| **计划 Plan** | 名称、优先级（高/中/低）、截止日期、备注、标签、关联想法、下挂 todo | 进行中 / 已完成 / 搁置 / 归档（归档不在桌面显示）|
| **待办 Todo** | 名称、截止日期、所属计划（可空 = 零散待办）、备注、标签 | 未做 / 进行中 / 完成（三态可自由来回切换；"进行中"在桌面今日区高亮）|
| **想法 Idea** | 文本、记录时间、补充内容、标签、关联到的计划或 todo（若已转化）| 未处理 / 已转化 / 已归档 |
| **洞察卡片 Insight** | 类型（关联 / 重复主题 / 方向）、内容、生成时间 | 未读 / 已读 / 已采纳 / 已忽略 |
| **标签 Tag** | 名称 | AI 推荐（控制数量、可一键拒绝）；用户可改名 / 合并 / 删除（删标签只去掉标签，不删内容）|
| **设置 Settings** | 洞察频率、通知开关 + 免打扰时段、随手记快捷键、快到期提醒、数据导出 | — |

**两层结构**：计划下挂 todo；也允许不属于任何计划的零散 todo。
**进度算法**：进度 = 已完成 todo 数 ÷ 该计划下**未删除**的 todo 总数。没有 todo 的空计划不显示进度条（显示"还没拆任务"）。

## 6. 三个界面 + 详情层级

### 6.1 桌面组件（常驻桌面背景）
三个区，每区**最多显示 3 条，多了折叠成"还有 N 个 →"**：
1. 计划进度条列表（名称 + 进度条 + 完成数）—— 归档/已完成的不显示。
2. 今日 / 快到期待办（3 天内到期；已过期标红置顶；"进行中"的高亮置顶）。
3. 最近想法。

**只读 + 两个快动作**：今日待办可直接**打勾完成 / 推迟**。点"推迟"弹几个选项（明天 / 本周末 / 下周 / 自定），推迟后它离开"今日"区，到点再回来。其余想编辑点名字直达工作区对应详情。数据一变**立即刷新**；**过午夜自动重算**"今天/过期"（按本机时区）。

### 6.2 工作区（点击桌面打开的窗口）
- **顶栏**：标题 + "＋ 随手记" + **搜索**。搜索范围 = 标题 + 正文 + 备注 + 补充内容，含已归档（结果里标出），不含回收站；可按标签 / 状态筛选。
- **侧栏**：计划 / 想法收集箱 / AI 洞察 / 设置。
- **列表 → 点名字 → 详情**：
  - **计划**：列表（含单独的"**零散待办**"区）→ 计划详情（改状态/优先级/日期/备注/标签、加 todo、看关联想法）→ todo 详情（改状态、移动到别的计划或移出变零散、备注）。
  - **想法收集箱**：顶部常驻输入框随时记 → 列表 → 想法详情（补充、标签、**转成计划**或**转成一条 todo**、归档、删除）。
  - **AI 洞察**：卡片列表（带状态，看过/没用的收起，旧的没动的自动归档）→ 点"深挖"转对话；卡片可"采纳为计划/todo"（复用想法转化流程）、可标"没用"反馈。
  - **设置**：见第 9 节。

### 6.3 随手记（零摩擦捕捉）
全局快捷键（任何应用可用，失焦不丢草稿）+ 工具内"＋ 随手记"按钮 + 收集箱顶部输入框。快捷键被占用时给提示，工具内入口始终是兜底。v1 仅 mac。

**窗口关系**：深链/点名字 = 打开工作区窗口并定位到该详情；关掉窗口即回到桌面。

## 7. 关键动线

1. **记想法**：快捷键/输入框 → 一句话 → 进收集箱（桌面"最近想法"实时更新）。
2. **想法 → 计划 / 待办**：想法详情转化 → AI 起草 → 我改 → 确认 →（可撤销）出现在计划列表/待办。
3. **看进度 → 改状态**：勾选 todo / 桌面打勾 → 进度条实时变化。
4. **AI 洞察 → 深挖**：卡片"深挖" → 对话，可追问；结论经我确认后回写到对应想法。
5. **桌面深链**：桌面点某计划/待办/想法 → 直达详情。

## 8. AI 能力详述（产品的灵魂）

- **职责**：会联想的思考伙伴，不是机械催办。三件事：① 串联想法与工作 ② 挖掘潜在关联/重复主题 ③ 指明方向。
- **交互**：洞察卡片速览 + 任意卡片点进去转对话深挖。
- **扫描范围**：不设死默认。手动唤起时 AI 先问"扫全部还是只看最近"；定时自动那次默认扫宽（全部历史想法 + 进行中的计划），以接住"挖跨时间关联"的价值。
- **能不能动我的数据**：AI **任何改数据的动作都先问一句、我点了才执行** —— 建 todo、把结论回写进想法、转计划/待办，统统要我确认，且会先说清它要改什么。执行后仍可撤销 / 进回收站兜底。**不存在 AI 静默改数据。**
- **结论沉淀**：对话里聊出来的结论，经我确认后回写到对应想法；对话历史保存（挂在来源卡片下，再点开能回到现场）。
- **砍掉"AI 速评"**：避免和洞察卡片重复，AI 输出集中在"定时洞察 + 主动问 + 转化协助"。
- **了结机制**：洞察卡片有状态；标"没用"的收起、并作为信号让以后少给这类；旧的没动的自动归档，主列表只留新鲜的。
- **少而精（落到机制，不只是口号）**：新洞察和"还没处理的旧洞察"比一比，太像就不出、或直说"暂时没新可串的点"；跨"工作/学习"两类只有确有呼应才串，证据不足不硬连。

## 9. 设置项

- **洞察生成频率**：每天早上 / 每周一次（默认）/ 每两周 / 手动触发。
- **通知**：洞察生成提醒（开/关）、快到期提醒（开/关）、**免打扰时段**（默认 22:00–9:00 不弹；快到期每天汇总弹一次，不逐条骚扰）。
- **随手记快捷键**：可自定义（默认 ⌘⇧Space），冲突时提示。
- **数据导出**：手动导出全部数据为一个文件（留底用，见第 12 节）。

## 10. 对象的删除 / 归档 / 撤销规则（生命周期）

这一节专门把"逆向和收尾动作"定清楚。

- **删计划**：默认**连同 todo 一起删**，删前弹确认，确认框里给"保留 todo（变零散待办）"的兜底选项。
- **回收站**：想法 / 计划 / todo 删除都是**软删除**，进回收站可恢复，约 30 天后自动清空。
- **想法归宿**：看过但不想做的 → **归档/搁置**（不占收集箱、不用真删，可随时翻出）。
- **进度口径**：进度按**现存（未删除）任务**算 —— 删掉一个还没做的任务，它就不算数，进度相应往前走（单人自用，不存在刷进度骗自己的问题）。
- **转化可撤销（有边界）**：
  - 想法可转成计划或一条 todo；刚转完有一个**撤销窗口**。
  - 撤销会删掉新建的计划/ todo，并把源想法退回"未处理"。
  - **若转化后你已经改过生成的内容**（改了计划、勾/移了 todo、又关联了别的想法、把源想法归档），撤销前会**提示这些后续改动会被一并撤销**，让你确认，绝不静默抹掉你后做的活儿。
  - 超过撤销窗口后，"一键撤销"消失，只能手动删除/整理。
- **todo 可移动**：在计划间移动，或"移出"变成零散待办；移动后相关计划进度重算。
- **断链处理**：计划被删 → 它来源的想法从"已转化"退回"未处理"；想法被删 → 计划"关联想法"栏显示"原想法已删除"，不报错。
- **洞察清理**：见第 8 节"了结机制"。

## 11. 排序规则（桌面与工作区一致）

桌面和工作区列表共用一套默认排序，避免两处顺序不一：
**先看紧急度**（已过期 > 今天 > 3 天内 > 其余）→ **再按优先级**（计划高 > 中 > 低，零散待办视作中）→ **同档按截止日期早的靠前** → 都没有则按最近修改。工作区列表可另外手动切换排序方式，默认值与桌面一致。

## 12. 边界与空状态（产品层面的"异常处理"）

- **首次使用**：做一个最简引导 —— 一两步说清"接住想法、看见进度、AI 帮你串"，顺手引导完成必要的系统授权（贴桌面、全局快捷键），并保证第一次就能跑通"记一条想法 → 看到它出现在桌面"这个闭环。
- **数据导出 / 备份**：数据只在本机，给一个手动"导出全部"（导成一个文件，自己存网盘/U盘），兜住"换电脑/重装/硬盘坏 → 全部归零"。**仅做导出留底，不做应用内导入/恢复**；真要找回需自己手动处理 —— 这是已知取舍。
- **空状态**：没有计划/想法/洞察时给友好引导文案（如"按 ⌘⇧Space 记下第一个想法"）。
- **AI 失败**：网络/服务异常时温和提示"稍后再试"，已有内容照常显示，不崩。
- **AI 内容太少**：不足以产出洞察时明说"再多记一些我就能帮你串了"，不硬凑。
- **想法去重**：完全相同的一句话重复记录时**温和提示**（不阻断"回车即走"）。
- **过期待办**：已过截止未完成的，桌面和列表里标红置顶。

## 13. 明确不做（v1 范围外）

- 手机端 / 多设备同步
- 多人协作、共享
- 纯生活目标模板（健身、读书打卡等）
- 第三方集成（日历、邮件、其它待办工具导入）
- 重复 / 周期任务（周报、周会这类每周都来的，先手动建）
- 应用内数据恢复 / 导入（只做手动导出留底）
- 定时洞察错过那次的补跑（关机/睡眠错过就跳过）

（注：标签/分类与关键词搜索**已纳入**；手动数据导出**已纳入**，不算同步。）

## 14. 成功标准（产品验收）

1. 任意应用里按快捷键 2 秒内记下想法并进收集箱；打字被打断不丢草稿。
2. 桌面组件常驻可见，三个区各最多 3 条、多了折叠；今日待办可直接打勾，"推迟"能选明天/本周末/下周/自定；数据变化立即刷新；过午夜自动重算日期。
3. 能建/改计划与 todo、设日期和优先级、调状态；勾选后进度按现存任务正确变化；空计划不显示进度条；"进行中"在桌面今日区高亮。
4. 点桌面或列表里的名字能进对应详情；todo 能在计划间移动/移出。
5. 想法能转成计划（AI 起草 + 我确认）或转成一条 todo，并可撤销；撤销若涉及后续改动会先提示确认；看过不做的可归档。
6. 删除走回收站可恢复；删计划有"保留 todo"兜底；断链不报错。
7. 能按设定频率收到洞察卡片，体现串联/挖关联/指方向；手动唤起时 AI 会问扫描范围；卡片可深挖、采纳、标"没用"；旧卡片自动归档。
8. AI 任何改数据的动作都先问、我确认后才执行；执行后可撤销；结论回写想法也需确认；对话历史保存。
9. 关键词 + 标签能搜到想法和计划（搜标题/正文/备注/补充，含已归档、不含回收站）；标签可改名/合并/删。
10. 能手动导出全部数据。
11. 通知遵守免打扰时段；各空状态/AI 失败有友好表现。
